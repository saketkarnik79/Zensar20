Azure SQL
	What is Azure SQL?
		It is Microsoft's fully managed relational database service in the cloud, based on the SQL Server engine. It is designed to store, manage, and query structured data using SQL.
	Types of Azure SQL
		Azure SQL Database
			Fully Managed (PaaS)
			Best for modern cloud apps
			No server management needed
		Azure SQL Managed Instance
			Near 100% SQL Server Comnpatibility
			Good for migrating existing apps
		SQL Server on Azure Virtual Machines
			Full Control (IaaS)
			You manage OS, patches, etc.
	Key Features
		Fully Managed
			Automatic Backups
			Patching & update handled by Azure
		High Availability
			Built-in replication
			99.99% uptime SLA
		Scalability
			Scale compute & storage easily
			Vertical & Horizontal scaling
		Security

			Encryption at rest & in transit
		Performance Intelligence
			Automatic tuning
